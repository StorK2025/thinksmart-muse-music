# 验证记录与范围

日期：2026-11-07。首个公开版本 0.1.0。

## 原始实机已经确认的功能

设备为 ThinkSmart View CD-18781Y，ARM64 Ubuntu 24.04，约 1.9 GiB RAM。

- 用户已确认：直接说“小麦小麦，你好，请用一句话介绍自己”，无需“问 Muse”，能听到完整回答。
- 默认 Hub provider 为 Muse，问句直达已配对的个人账号；未调用 DeepSeek 生成回答。
- 同一个 Muse 专用会话两轮合成测试，第二轮能记住第一轮给出的测试代号。
- 实际 Hub 文字→Muse→TTS→音频返回测试成功：37 个音频包，首包 21.79 秒，总计 24.13 秒。这里只是一次样本，不代表每次延迟。
- 用户已确认网易云语音点歌及暂停/继续可用；原实现已部署歌词、当前队列、歌单、播放全部与循环模式。
- 单次资源样本：Muse 服务约 24 MiB，整机可用内存约 816 MiB。没有在音箱本地运行大模型；不保证所有场景的资源占用相同。

## 本次公开版抽取后的验证

在原设备的独立临时目录运行，没有覆盖正在使用的代码、重启服务或重新配对：

| 检查 | 结果 |
| --- | --- |
| `install.sh --check` | ARM64 / Ubuntu 24.04 / Hub / 本地识别 / EdgeTTS 通过 |
| SDK 事件顺序、流式回复、断开清理 | 7 项通过 |
| 配对时的代理网络检查 | 4 项通过 |
| Muse provider 当前问句、会话复用、音乐路由、重放和打断 | 7 项通过 |
| 配置合并、账户数据保留、回退、链接恢复、代理限制 | 9 项通过 |

另有 Windows 本机配置测试、Linux ShellCheck、Python/JavaScript/PowerShell 语法检查，以及公开源码凭据扫描。

Linux 隔离目录还通过了 2 项安装编排测试：模拟首次安装及手动恢复，以及模拟服务启动失败后的自动恢复。测试实际执行文件复制、配置修改和备份恢复；账号创建、系统服务与网络操作用替身隔离，不会改动测试主机系统。合计 29 项回归，另有界面测试。

播放器用**合成网页夹具**做无账号浏览器测试：挂载界面、歌曲名、暂停/继续、歌词变化、单曲循环、当前队列、切到原页及返回均通过，没有访问真实音乐账号。此测试证明本包界面/控制代码内部协作正常，不能代替网易云官网未来改版后的实测。

## 尚未验证的部分

- 没有用第二台恢复出厂后的设备走完“刷机→公开安装器→新账号配对→会员点歌”的全流程。
- 可选 Mihomo 安装器校验了版本/官方摘要，并有配置限制测试；没有为测试目的删除现有代理后重新安装。
- 不保证所有 Muse 账号都有开发者设备入口，也不保证所有网易云会员歌曲都支持网页播放。
- 长时间运行、多账号、多设备网关、其他系统版本和其他机型不在 0.1.0 的实机验收范围。

因此发布为**实验版**。新设备请先完成基础镜像备份，保留安装器打印的配置恢复路径。
